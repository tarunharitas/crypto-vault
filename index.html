Cryptographic Architecture

Zero Trust. Maximum Hardening.

Designed to withstand GPU brute-force clusters, offline SQLite tampering, and memory side-channels.

Argon2id Memory-Hard Key Derivation

Configured with 64 MiB of memory, 3 iterations, and 4 threads to make password cracking economically unfeasible for GPU rigs and ASICs.

Memory: 64 MiB RAM Parallelism: 4 Threads ASIC Immune

AES-256-GCM + AAD v2

Length-prefixed binary Authenticated Associated Data binds usernames directly to the ciphertext tag, preventing record splicing attacks.
